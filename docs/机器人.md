# 聊天机器人（Telegram / 飞书）

不打开 App 也能学：机器人每天定时推 3 道复习题和 1 句跟读，在聊天里点按钮、回复拼写、发语音就行。答过的题按 FSRS 记进复习，App 下次同步时合进来，算当天练过。

**这是给会自己部署的人用的。** 日日说不提供机器人服务，也不提供同步服务器：聊天机器人要有一台一直开着的机器替你收飞书 / Telegram 的消息，手机 App 放到后台会被系统冻结，做不到这一点；不想折腾的话，App 里的“通知里做题”不用任何服务器，也能不打开 App 就复习。

自己部署需要两样，都跑在你自己的服务器上，用你自己的机器人凭据：
1. **自建同步服务**（`packages/sync-server`）：机器人以“一台同步设备”的身份读写你的学习记录。只存加密后的数据。
2. **机器人**（`packages/bot`）。

然后在 App 里：设置 → 数据 → 自建同步服务器，填 `https://你的域名/api/sync` 开启，拿到同步码，再把同步码发给机器人绑定。绑定后机器人能读到你的记录（为了出题），随时发“解绑”就断开。

## 用法（在聊天里发）
| 发 | 做什么 |
|---|---|
| `绑定 XXXX-XXXX-…` | 绑上同步码（App：设置 → 数据 → 自建同步服务器 → 同步码 → 显示） |
| `复习` | 马上来 3 道题：看英文选意思（按钮）、看中文拼写（直接回复英文） |
| `跟读` | 给一句话，发语音过来打分，告诉你哪几个词没读准 |
| `时间 21:00` | 改每天推送的时间（默认 20:30，北京时间） |
| `解绑` | 机器人不再读你的记录 |

## 部署
1. 同步服务：`bash scripts/deploy-sync.sh`（systemd `sayday-sync`，只听 127.0.0.1:5296）。App 要连它，在你的反向代理里加一段（要 HTTPS）：
   ```
   location ^~ /api/sync/ {
       client_max_body_size 7m;
       proxy_pass http://127.0.0.1:5296;
       proxy_set_header X-Real-IP $remote_addr;
   }
   ```
2. 机器人：凭据写进 `/etc/sayday-bot.env`（只有 root 能读），然后 `bash scripts/deploy-bot.sh`。机器人和同步服务在同一台机器上，直接连 127.0.0.1，不用改。

```
# Telegram：在 @BotFather 那里 /newbot 拿到的 token
TELEGRAM_TOKEN=
# 飞书：开放平台建“企业自建应用”，开启机器人能力
FEISHU_APP_ID=
FEISHU_APP_SECRET=
# FEISHU_VERIFY_TOKEN=   只有用回调地址时才要
# 可选
# TZ_MIN=480            时区（分钟，北京时间 480）
# SYNC_API=http://127.0.0.1:5296/api/sync   同步服务在别的机器上才要改
```

### 飞书后台要配的（默认长连接，不用公网回调地址）
- 应用能力：开启“机器人”
- 权限管理：`im:message`（读消息）、`im:message.p2p_msg:readonly`（私聊消息）、`im:message.group_at_msg:readonly`（群里 @ 机器人的消息）、`im:message:send_as_bot`（发消息）、`im:resource`（下载语音）
- 事件与回调 → 事件配置：订阅方式选“**使用长连接接收事件**”（机器人服务要先在跑，后台才能保存），添加事件 `im.message.receive_v1`
- 事件与回调 → 回调配置：同样选长连接，添加 `card.action.trigger`（卡片上的按钮）
- 版本管理与发布：创建版本、发布（企业内自建应用一般自动通过）
- 然后在飞书里搜你建的机器人，私聊发“帮助”

想改用回调地址：在 `/etc/sayday-bot.env` 加 `FEISHU_VERIFY_TOKEN`（后台“加密策略”里的 Verification Token，Encrypt Key 不要设），重新 `bash scripts/deploy-bot.sh`；反向代理里把 `/api/bot/feishu` 转到 `127.0.0.1:5299`，后台请求地址填 `https://你的域名/api/bot/feishu`。

Telegram 用长轮询收消息，不需要回调地址。
