# 聊天机器人（Telegram / 飞书）

不打开 App 也能学：机器人每天定时推 3 道复习题和 1 句跟读，在聊天里点按钮、回复拼写、发语音就行。答过的题按 FSRS 记进复习，App 下次同步时合进来，算当天练过。

机器人在服务器上跑（`packages/bot`），以“一台同步设备”的身份读写你的学习记录，所以**要先在 App 里开多设备同步**，再把同步码发给机器人绑定。绑定后机器人能读到你的记录（为了出题），随时发“解绑”就断开。

## 用法（在聊天里发）
| 发 | 做什么 |
|---|---|
| `绑定 XXXX-XXXX-…` | 绑上同步码（App：设置 → 数据 → 多设备同步 → 同步码 → 显示） |
| `复习` | 马上来 3 道题：看英文选意思（按钮）、看中文拼写（直接回复英文） |
| `跟读` | 给一句话，发语音过来打分，告诉你哪几个词没读准 |
| `时间 21:00` | 改每天推送的时间（默认 20:30，北京时间） |
| `解绑` | 机器人不再读你的记录 |

## 部署
凭据写进 `/etc/sayday-bot.env`（只有 root 能读），然后 `bash scripts/deploy-bot.sh`。

```
# Telegram：在 @BotFather 那里 /newbot 拿到的 token
TELEGRAM_TOKEN=
# 飞书：开放平台建“企业自建应用”，开启机器人能力
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_VERIFY_TOKEN=
# 可选
# TZ_MIN=480            时区（分钟，北京时间 480）
# SYNC_API=https://sayday.ivyea.com/api/sync
```

### 飞书后台要配的
- 权限：`im:message`（接收消息）、`im:message:send_as_bot`（发消息）、`im:resource`（下载语音）
- 事件与回调 → 请求地址：`https://sayday.ivyea.com/api/bot/feishu`；订阅事件 `im.message.receive_v1`；回调订阅 `card.action.trigger`（卡片按钮）
- 加密策略：Verification Token 填进 `FEISHU_VERIFY_TOKEN`；**Encrypt Key 不要设**
- 发布应用版本后，在飞书里找到机器人发“帮助”

Telegram 用长轮询收消息，不需要回调地址。

## 测试
`node --test packages/bot/test/*.test.mjs`：本机起同步服务 + 模拟一台 App 设备，跑绑定、复习、跟读、定时推送、解绑；Telegram / 飞书用假接口验证消息格式。
