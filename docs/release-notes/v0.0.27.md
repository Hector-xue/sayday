**面对面同步 · AI 入口好找了**

可以在 App 里直接更新（设置 → 关于 → 检查更新），学习记录都在。

- 同步改成面对面同步：两台设备连同一个 Wi-Fi（没有 Wi-Fi 就一台开热点、另一台连上），设置 → 数据 → 面对面同步，一台“出码”，另一台扫一下（或者手动输入地址和配对码），学习记录直接在两台之间传、合到一起。不经过任何服务器，不用账号。手机、电脑版都能用
- 新手机第一次打开：欢迎页点“在别的设备上用过？接过来”，扫旧手机出的码就行，不用重新定级；旧设备不在身边就导入备份文件
- 原来的同步码同步停了（日日说不再提供同步服务器），本机的学习记录都在，不受影响。会自己部署的人可以在 设置 → 数据 → 自建同步服务器 接自己的服务器（聊天机器人也要它，见 docs/机器人.md）
- 学习搭子去掉了（它离不开一个大家共用的服务器）
- 浏览器划词插件：收的词改成在插件里“导出收的词”，再在 App 设置 → 导入备份 里选这个文件，合进词库（已有的词和学习记录不会被覆盖）
