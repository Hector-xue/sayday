**新界面 + 更懂中国口音的发音打分**

从 v0.0.5 直接覆盖安装，学习记录都在。第一次跟读会重新准备一次打分模型，稍慢几秒。

- 全新界面，设置 → 外观里三种风格随时切换，每种都有深色版：
  - 荧光笔（默认）：白纸黑字，重点用荧光黄划出来
  - 纸与墨：暖纸色、宋体标题、书籍衬线英文，像一本读本
  - 经典：原来的蓝色
- “今天”页顶部改成连续天数 + 最近 7 天
- 发音打分换成用中国学习者录音微调过的模型：逐个音标的打分更准，读错的音能查出约 75%（原来约 61%），读对的音被误标红的情况没有变多
- 修：听力“开始播放”按钮的字被挤成竖排；剧集页季数按钮折行；听力练习暂停 / 重听时可能两段声音叠在一起
