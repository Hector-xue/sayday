- 剧集两季 20 集：《Life in London》（A2→B1）+《Edinburgh》（B1→B2），一天解锁一集；听 → 演（你演林，逐句跟读打分）→ 听力理解题 → 收生词
- 接入你自己的 AI（DeepSeek / 通义 / Kimi / 智谱 / OpenAI / Claude 等，密钥只存在手机上）：
  - 和 Emma 聊天：按你的水平说话，顺手纠正明显的错，记得你说过的事
  - 双语日记：逐条改错、给更地道的版本，可以逐句跟读
- 雅思口语模考：Part 1 / 2 / 3 完整走一遍，本机识别你说的话，给流利度和发音；接了 AI 再按四项标准打分、给建议和参考回答
- 雅思写作批改：大作文 / 书信，AI 按四项标准打分、逐句改错、给 7.5 分改写
- 备份可以导入了：换手机、重装后用导出的文件恢复
- 说话代替打字：和 Emma 聊天、写日记都能直接说（本机识别，第一次要下载 63MB 模型，录音不上传）
- 每日提醒：设置里打开，当天练过就不打扰
- 发音实验室：弱项专项练习、10 组最小对立（先听辨再说对）、39 个音标口型图、语调曲线对比、示范逐词高亮
- 水平持续校准：每周 1 分钟小测、学会的词实时计入、降档要连续两次证据；每日练习加听力题，听力水平单独估
- 进步页：词汇 / 听力 / 发音分项，同一句的第一次和最近一次录音对比
- 修复：改目标或重测后卡在引导页
