**雅思专项 + 第三季 + 桌面小组件**

从 v0.0.4 直接覆盖安装，学习记录都在。

- 雅思听力：原创两套，每套 4 部分 40 题。默认和真考一样只放一遍；练习模式可以暂停、重听上一句。交卷后逐题看答案和中文解析，录音原文每句都能重听
- 雅思阅读：原创两套，每套 3 篇 40 题（判断、单选、段落标题、信息定位、摘要选词、填空）。可以一篇一篇练，也可以 60 分钟整套模考；交卷后原文里标出每题的依据
- 分数按官方常用换算表估算，进步页显示听力 / 阅读
- “今天”页新增“雅思专项”：听力、阅读、口语模考、写作放在一起（目标是雅思时显示）
- 剧集第三季《Back in London》（B2→C1，10 集）：回伦敦备考 7 分、难缠的客户、用数据汇报、考试日、面试、研讨课……第二季看完后接着解锁
- 安卓桌面小组件：连续天数、今天练没练、一个最近在学的词，点一下打开 App（长按桌面 → 小组件 → 日日说）
