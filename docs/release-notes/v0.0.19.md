**进步看得见：雅思四项预估、词汇量曲线、能做到的事、声音日记**

可以在 App 里直接更新（设置 → 关于 → 检查更新），学习记录都在。

- 进步页加雅思四项预估雷达图（听说读写 + 总分，按周存一份，虚线是四周前）。每项写明依据是哪些练习；还没依据的那项告诉你做什么就有
- 词汇量曲线：定级、每周小测和每周估算连成一条线
- “你现在能做到”：用能做到的事说进步（出国问路点餐、听懂 BBC 6 Minute English、读懂新闻大意……），每条写明哪天做到的；没做到的告诉你还差什么。今天页会提示新做到的事
- 声音日记：每周用同一段话录一次，自动打发音分、记语速和停顿，几周后和第一周对着听。录音只存在本机
