**桌面小组件六种 · 拼写练习 · 雅思全真模考**

可以在 App 里直接更新（设置 → 关于 → 检查更新），学习记录都在。

- 桌面小组件改成六种：本周（七天打点）、今天、单词卡（能“换一个”）、今日剧集、开练（1×1）、综合。设置 → 提醒与小组件 → 桌面小组件 → 看看：用你现在的数据预览，每种一键“添加到桌面”。小组件上的按钮直接打开对应的地方（开练、今日剧集、词库）
- 修了小组件的几个问题：综合那个在两行高的桌面上被截掉一截；只做了复习不会刷新；过了凌晨 4 点最多要等一小时才变成新的一天
- 修了“通知里做题”“每日提醒”开关打不开：已经允许过通知的手机上，开关会一直卡住
- 拼写：每天的复习里，熟一点的词会改成听音写词（逐字标出写错的字母）；词库页新增“听写”，一次 10 个学过的词
- 模拟考试（今天页，所有人都有）：雅思全真模考，听力 → 阅读 → 写作 → 口语按真考时长和顺序走，阅读、写作到点自动交卷，中途可以退出接着考，考完出四项分数和总分；也能单练每一项
- 写作新增学术类小作文（Task 1）：折线图、柱状图、饼图、表格四道，AI 会核对你引用的数字对不对
- AI 回复（用 DeepSeek 实测后调整）：Emma 主动找你时按她的性格说话；翻译里不再夹英文；工作英语的改写版不会出语法错
