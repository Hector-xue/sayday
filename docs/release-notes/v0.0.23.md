**多设备同步 · 学习搭子 · 通知里直接做题**

可以在 App 里直接更新（设置 → 关于 → 检查更新），学习记录都在。

- 多设备同步：设置 → 数据 → 多设备同步 → 开启，会给你一个同步码。在另一台设备（手机、网页版、平板）输入它就接上了，新装的 App 在欢迎页就能输入，不用重新定级。之后打开 App、练完一组都会自动同步
- 同步是端到端加密的：同步码只在你的设备上，服务器上存的是解不开的密文。录音不同步
- 学习搭子：进步页可以建一个小组，把小组码发给朋友。组里只看每个人本周练了几天，不排行、不比分数
- 安卓 App：设置 → 提醒与小组件 → 通知里做题。每天到点在通知里弹 3 道复习题（看英文选意思、看中文拼单词），点按钮或直接在通知里输入就能答，答了就算今天练过，复习进度也跟着更新。默认关着，可以先点“试一下”
