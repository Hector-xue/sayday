**桌面版 · 浏览器划词插件**

可以在 App 里直接更新（设置 → 关于 → 检查更新），学习记录都在。

- 桌面版：Windows、macOS、Linux 都有安装包（在 GitHub Release 页下载），和手机用同一个同步码就能接上学习记录
- 浏览器插件（Chrome / Edge）：网页上双击或选中英文单词，旁边弹出释义，一键“收进日日说”，连你当时看到的那句话一起收。填上同步码后，收的词会出现在 App 的复习里，并显示“你在网上见过它”和原句
- 安装插件：下载 Release 里的 sayday-extension zip，解压，浏览器打开“扩展程序 → 开发者模式 → 加载已解压的扩展程序”，选解压出来的文件夹
