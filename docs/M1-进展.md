### 2. 安卓原生推理（Tauri 插件 `sayday-infer`）
- 前端 → Rust 命令 → Kotlin：用 `onnxruntime-android` 推理，用 `AudioRecord` 原生录音（VOICE_RECOGNITION 音源，多数机型会关掉自动增益和降噪）。
- 音频和 logits 都用 base64 编码的 float32 传输。
- 评分仍在 JS 里做，和网页版共用 `gop.mjs` / `calib.mjs`，**两端分数口径完全一致**。
- 模型不入库：CI 从 Hugging Face 下载原始权重，现场导出 int8 ONNX，结果缓存。
- 坑：
  - tauri 钉到 2.11.5 后，如果没有 Cargo.lock，tauri-runtime 会漂移到不兼容版本，编译失败。现在借用已验证的 lock，再回填 CI 实际解析出的 lock。
  - gradle 构建时会回调 `npm run tauri`，所以必须有 package.json，不能用 npx 临时调用 CLI。
  - debug 包带完整调试信息，单个 .so 就有 118MB，已在 dev 档关掉。

### 3. 加尾音 / 漏尾音检测
第一版拿“贪心识别序列”和标准读音对齐，噪声太大，不可用：

| 方法 | 漏尾音查准 | 漏尾音召回 | 加尾音：被标词人工分 / 其余 | 好句子误标 |
|---|---|---|---|---|
| 贪心对齐 | 0.17 | 0.19 | 9.10 / 9.45 | 5.2%（句） |
| **CTC 似然比（采用）** | **0.33**（LLR>5） | **0.66** | **8.55 / 9.39**（LLR>3） | **1.1%（词）** |

- 做法：对每个以辅音结尾的词，比较“标准读音”和“后面多一个元音”“这个辅音被删掉”两种假设的 CTC 似然；复用前向/后向表，单句约 4ms。
- speechocean762 **没有标注加尾音**，所以加尾音只能间接验证（被标出词的人工分明显偏低，好句子里很少误标）。
- 漏尾音的查准率仍然偏低，界面上只用黄色的“可能没读出来”提示。

### 4. 句子级评分 v2
特征：音素校准分（均值、最小值、低分比例）+ 词尾检测（加尾音、漏尾音的比例和强度）+ 语速。用线性模型，权重写进 `calib.json`，前端直接计算。

| 特征 | 句子级相关 | 成人 |
|---|---|---|
| 仅音素分均值 | 0.568 | 0.641 |
| + 音素分统计 | 0.612 | 0.681 |
| + 词尾检测 | 0.651 | 0.714 |
| **+ 语速（采用）** | **0.670** | **0.756** |

| 例句（浏览器全链路，含录音编码） | 人工 | M0 | M1 |
|---|---|---|---|
| Just set hook and put the pressure | 40 | 85 | **59**（标出 just / set / put 加尾音） |
| Mark is going to see elephant | 90 | 98 | 84（无误报） |

### 5. 真机测速结果（2026-10-11，小米 M610BB / Android 17，8 核）
| 端 | 每 1 秒音频耗时 | 3 秒句子 |
|---|---|---|
| 手机网页（单线程 WASM） | 0.40 秒 | 约 1.2 秒 |
| 安卓 App 1 线程 | 0.109 秒 | 约 0.33 秒 |
| 安卓 App 4 线程 | 0.059 秒 | 约 0.18 秒 |

App 录音到出分全链路约 1.2 秒（9.6 秒录音）。网页版速度够用，暂不做 WebGPU。

### 6. 自然人声示范（替换浏览器自带 TTS）
- 引擎：Kokoro-82M（Apache-2.0），美音 `af_heart`、英音 `bf_emma`，语速 0.95。
- 预置句子：服务器用 fp32 模型预生成 WAV（`spikes/tts/gen.mjs`），离线缓存，点了就播。
- 自定义句子：浏览器里用 kokoro-js（q8，约 90MB，首次按需下载）现场合成，模型和 wasm 都从本站取。
- 质检：用自己的发音评分给示范打分（`spikes/tts/score_wav.mjs`），10 条预置 + 浏览器合成全部 88~91 分，零红黄、零尾音报警。
- 已知问题：浏览器单线程合成一句约 8~11 秒（服务器 CPU 实测），首次还要下载模型；正式课程内容应全部预生成，现场合成只留给用户自己输入的句子。
- 授权：kokoro-js 打包的 eSpeak NG 是 GPL-3.0，正式发版前需评估或替换音素化方案。
