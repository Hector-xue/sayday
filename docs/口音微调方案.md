# 中国口音微调方案（待拍板）

## 为什么要做
现在的音素模型（charsiu wav2vec2 CTC）是用母语者语料训练的。在中国学习者的数据（speechocean762）上，校准后的音素级打分和人工评分的相关是 **0.60**，整句 **0.67**（成人 0.76）。主要误差来自：
- 中国学习者常见的替换（/θ/→/s/、/v/→/w/、/l/↔/n/）在模型里概率被压得很低，GOP 分辨不够细；
- 词尾加元音、吞辅音这类现象，模型没见过多少。

## 做法
1. 数据：speechocean762 训练集（2500 句，CC BY 4.0，带人工音素标注）+ Common Voice 英语里标了“中国口音”的子集（CC0）。**不用 L2-ARCTIC**（CC BY-NC，会让模型带上“非商用”限制，和 MIT 开源冲突）。
2. 在 charsiu 模型上继续训练 CTC（冻结特征提取层，学习率 1e-5，约 20 个 epoch），用学习者“实际读出的音素”做标签，让模型学会认出读错的音。
3. 重新导出 int8 ONNX，重跑 `spikes/m0` 的校准与评测脚本，对比音素级相关、整句相关、尾音检测的查准 / 召回。
4. 只有指标确实变好才替换 App 里的模型（同时更新 calib.json）。

## 成本
- 需要一块 24GB 显存的 GPU（RTX 4090 / A10 级别）。按小时租的平台（如 AutoDL）约 2~3 元 / 小时。
- 一次完整训练加评测约 6~10 小时，**单次约 20~40 元**；调两三轮参数，总共预计 **100 元以内**。
- 本机（2 核 CPU、无 GPU）跑不动。

## 预期
- 音素级相关 0.60 → 0.65~0.70（同类公开工作的典型提升幅度，不保证）。
- 对中国学习者最常见的几类错误更敏感，误报不应变多（会用“好句子误标率”把关）。
